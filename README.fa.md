# آرشیو فیلم

برنامه‌ای برای ویندوز که فیلم‌ها، سریال‌ها و انیمه‌های تو چند هارد مختلف رو فهرست می‌کنه. اسم هر پوشه رو می‌خونه، فیلم رو تشخیص می‌ده و پوستر، خلاصهٔ داستان و اطلاعاتش رو از IMDb (از طریق OMDb) می‌گیره. اگه چیزی تو IMDb پیدا نشد، برای انیمه از MyAnimeList (از طریق Jikan) استفاده می‌کنه. رابط برنامه فارسی و انگلیسیه.

برنامه هیچ فایلی روی هاردهات رو تغییر نمی‌ده، جابه‌جا نمی‌کنه و پاک نمی‌کنه. فقط اسم پوشه‌ها رو می‌خونه.

## نصب و اجرا

۱. Node.js (نسخهٔ ۲۲ یا بالاتر) رو نصب کن.
۲. تو پوشهٔ پروژه این دستورها رو بزن:

```
npm install
npm start
```

برای ساختن فایل نصب ویندوز (باید روی خود ویندوز اجرا بشه):

```
npm run dist
```

فایل نصب تو پوشهٔ `dist` ساخته می‌شه.

## کلید OMDb

برای گرفتن اطلاعات فیلم یه کلید رایگان لازمه. از سایت omdbapi.com کلید رایگان بگیر و تو «تنظیمات» وارد کن. نسخهٔ رایگان روزی حدود ۱۰۰۰ درخواست داره. اگه آرشیوت بزرگه، وقتی سهمیه تموم شد برنامه می‌ایسته و فردا با زدن «دریافت اطلاعات» از همون جا ادامه می‌ده.

## اضافه کردن پوشه‌های آرشیو

۱. هارد رو وصل کن.
۲. دکمهٔ پوشه (بالای برنامه) رو بزن، آدرس پوشهٔ فیلم‌ها رو بنویس (مثلاً `E:\Movies`) یا با «انتخاب…» پیداش کن و «افزودن پوشه» رو بزن. وقتی آرشیو خالیه، صفحهٔ اصلی خودش یه دکمهٔ «افزودن پوشه» نشون می‌ده.
۳. «اسکن پوشه‌ها» رو بزن. برنامه پوشه‌های زیر اون آدرس رو تا چند سطح می‌گرده (بخش «تشخیص پوشه‌ها» رو ببین).
۴. «دریافت اطلاعات» رو بزن تا پوستر و اطلاعات گرفته بشه.

### اسکن هوشمند

هر بار «اسکن پوشه‌ها» رو بزنی، فقط چیزهای جدید اضافه می‌شن. مثلاً دیروز ۱۱۰ فیلم اسکن کردی و امروز ۱۲۰ تا داری: ۱۱۰ فیلم قبلی با همهٔ اطلاعاتشون (پوستر، داستان، اصلاح‌های دستی، ترجمه) دست‌نخورده می‌مونن و ۱۰ فیلم جدید اضافه می‌شن. بعد از اسکن پیام می‌گه چند مورد جدید اضافه شد. «دریافت اطلاعات» هم فقط برای همون مورد‌های جدید درخواست می‌فرسته، پس سهمیهٔ OMDb الکی خرج نمی‌شه. پوشه‌ای که از هارد پاک یا عوض اسم بشه «پوشه گم شده» می‌گیره و از آرشیو پاک نمی‌شه.

### افزودن یک فیلم یا پوشهٔ تکی

اگه فقط یه فیلم (یا یه سریال) می‌خوای، نه کل یه پوشه: آدرس همون پوشه رو تو کادر بنویس و «افزودن یک فیلم/پوشه» رو بزن. فقط همون پوشه یه عنوان حساب می‌شه و پوشه‌های کنارش اسکن نمی‌شن (کنارش تو لیست برچسب «تکی» می‌خوره). اگه پوشه چند فصل داشته باشه، فصل‌ها جدا شناخته می‌شن. آدرس باید پوشه‌ای روی یه هارد متصل باشه، نه خودِ ریشهٔ هارد.

هر هارد با سریال خودش شناخته می‌شه، نه با حرف درایو. پس اگه یه روز حرف درایو عوض بشه، چیزی گم نمی‌شه. وقتی هارد جدا باشه، آرشیوش تو برنامه می‌مونه و برچسب «هارد جدا شده» می‌گیره.

پوشهٔ خالی هم تو آرشیو ثبت می‌شه و برچسب «پوشه خالی» می‌گیره. اگه پوشه‌ای بعداً حذف یا تغییر نام بده، برچسب «پوشه گم شده» می‌گیره و از آرشیو پاک نمی‌شه.

## تشخیص پوشه‌ها (اسکن بازگشتی)

برنامه فقط پوشه‌هایی رو می‌گرده که خودت اضافه کردی. هر پوشه به این ترتیب بررسی می‌شه:

1. اگه اسمش تو فهرست نادیده‌گرفتن باشه (`Subtitles`، `Extras`، `Specials`، `CD1`، `Disc 2` و مانند اون)، رد می‌شه.
2. **پوشهٔ فصل:** اسمش `S01`، `Season 1` یا `فصل 1` داره. اسم سریال متن قبل از اون توکنه؛ اگه خالی بود، اسم پوشهٔ بالاییه. پس `Mentalist/Mentalist S01` و `Mentalist/Season 1` هر دو می‌شن «Mentalist». داخل پوشهٔ فصل نمی‌ره و هر پوشهٔ فصل یه مکان حساب می‌شه.
3. **پوشهٔ سریال یا دسته:** اگه زیرپوشهٔ فصل داره، یا تو «پوشه‌های مجموعه» ثبت شده، یا فقط زیرپوشه داره (بدون فایل ویدیو و بدون سال تو اسمش)، داخلش می‌ره و خودش مکان حساب نمی‌شه.
4. غیر از اینا، **یه فیلم (یه عنوان)** حساب می‌شه، حتی اگه خالی باشه.

**پوشهٔ مجموعه (مثل Batman Trilogy):** اگه یه پوشه چند فیلم داخلش داشته باشه، به‌جای اینکه یه پوشهٔ ناقص حساب بشه، هر فیلمش جدا شناخته و به آرشیو اضافه می‌شه. فیلم‌ها می‌تونن زیرپوشه باشن (`Batman Begins (2005)`) یا خودِ فایل‌های ویدیو (`Batman.Begins.2005.1080p.mkv`)؛ برای فایل‌ها اسم فایل (بدون پسوند) اسم فیلم حساب می‌شه. نمونه (`sample`)، تریلر، قسمت‌های سریال (`S01E01`) و بخش‌های دیسک (`CD1`، `part1`) فیلم جدا حساب نمی‌شن. اگه پوشه خودش سال داشته باشه و فایل‌هاش سال نداشته باشن (مثل `Inception (2010)`) یه فیلم حساب می‌شه. خود پوشه هم تو آرشیو یه کارت «مجموعه · N عنوان» می‌گیره (فقط تو تب «همه») و وقتی روش بزنی، دکمهٔ «باز کردن پوشه» و فهرست فیلم‌های داخلش رو می‌بینی؛ با زدن روی هر فیلم می‌ری سراغ جزئیاتش. مجموعه‌ای که فقط یه عنوان داخلش باشه کارت جدا نمی‌گیره. برای فایل‌ها، «باز کردن پوشه» پوشهٔ نگه‌دارندهٔ فایل رو باز می‌کنه، نه خودِ فیلم رو.

فایل ویدیو یعنی `mkv mp4 avi mov wmv m4v ts m2ts mpg mpeg flv webm iso vob`. عمق بیشینه ۸ سطحه و شورتکات‌ها دنبال نمی‌شن. پوشه‌ای که برنامه نتونه بخونتش (مثلاً دسترسی نداره) «گم شده» حساب نمی‌شه.

## الگوی نام پوشه‌ها

تو «تنظیمات» می‌تونی بنویسی پوشه‌هات چه شکلی اسم‌گذاری شدن. هر خط یه الگوئه. این‌ها رو می‌تونی استفاده کنی:

- `{title}` اسم فیلم
- `{year}` سال ساخت
- `{season}` شمارهٔ فصل
- `*` هر چیز اضافه‌ای که بعدش می‌یاد

مثال‌ها:

| الگو | پوشه‌ای که می‌خونه | نتیجه |
| --- | --- | --- |
| `{title} {year}*` (پیش‌فرض) | `batman 2022` | The Batman، ۲۰۲۲ |
| `{title} {year}*` | `The.Batman.2022.1080p.BluRay` | The Batman، ۲۰۲۲ |
| `{title} ({year})*` | `Joker (2019) [1080p]` | Joker، ۲۰۱۹ |
| `{title} S{season}` | `Breaking Bad S02` | Breaking Bad، فصل ۲ |

فاصله، نقطه، خط تیره و آندرلاین یکی حساب می‌شن و فرق حروف بزرگ و کوچک مهم نیست. الگوها به ترتیب امتحان می‌شن و اولین الگوی درست استفاده می‌شه. اگه پوشه‌ای با هیچ الگویی نخونه، برنامه خودش حدس می‌زنه و برچسب «حدسی، بررسی کن» می‌ذاره.

پوشه‌هایی مثل `Subtitles`، `Extras` و پوشه‌های سیستمی خودکار نادیده گرفته می‌شن. اگه پوشه‌ای مثل `Marvel Collection` چند فیلم داخلش داره، تو «تنظیمات» بخش «پوشه‌های مجموعه» مسیرش رو بنویس (مثلاً `Movies/Marvel`) تا هر فیلمِ داخلش جدا ثبت بشه.

## برچسب‌ها

- **نیاز به بررسی:** برنامه فیلم رو مطمئن تشخیص نداد. روش بزن، از لیست پیشنهادها انتخاب کن یا لینک بده.
- **در انتظار اطلاعات:** هنوز «دریافت اطلاعات» برای این مورد اجرا نشده یا سهمیه تموم شده.
- **حدسی، بررسی کن:** الگوی شما با اسم پوشه نخوند و برنامه خودش اسم رو حدس زد.
- **پوشه خالی / پوشه گم شده / هارد جدا شده:** وضعیت پوشه روی هارد.

اسم پوشه‌های فارسی رو OMDb نمی‌شناسه. این‌ها «نیاز به بررسی» می‌شن و باید عنوان انگلیسی رو با لینک بدی. اسم فارسی پوشه همیشه قابل جستجوئه.

## اصلاح اطلاعات آنلاین

اگه اطلاعات یه فیلم اشتباهه، روش بزن و تو بخش «اصلاح اطلاعات آنلاین» لینک IMDb یا OMDb اون فیلم رو بذار، مثلاً:

```
https://www.imdb.com/title/tt1877830/
```

برنامه شناسهٔ `tt...` رو از لینک درمیاره و اطلاعات و پوستر رو با همون شناسه عوض می‌کنه. این اصلاح ثابت می‌مونه و اسکن‌های بعدی عوضش نمی‌کنن. اگه تو لینک OMDb کلید API باشه، برنامه نادیده‌ش می‌گیره و فقط کلید تنظیمات رو استفاده می‌کنه. این گزینه برای انیمه‌هایی که از MyAnimeList اومدن فعلاً لینک MyAnimeList رو قبول نمی‌کنه.

## وقتی OMDb اسم پوشه رو پیدا نکنه

برنامه تو OMDb جستجو می‌کنه. اگه یه نتیجهٔ واضح باشه (هم‌اسم یا خیلی نزدیک، و سالش حداکثر یه سال فرق داشته باشه)، خودش وصلش می‌کنه و برچسب «حدسی، بررسی کن» می‌ذاره. اگه چند نتیجه باشه (مثلاً Dune ۱۹۸۴ و ۲۰۲۱ وقتی سال تو اسم پوشه نیست)، «نیاز به بررسی» می‌شه و خودت از لیست انتخاب می‌کنی. نتیجهٔ جستجوها تو دیتابیس می‌مونه و تکراری پرسیده نمی‌شه.

## ظاهر برنامه

- **تم تیره و روشن:** دکمهٔ ماه/خورشید بالای برنامه. تا انتخاب نکنی، تم سیستم ویندوز رو دنبال می‌کنه و انتخابت یادش می‌مونه.
- **صفحه پوستر محوره:** کارت‌ها پوستر بزرگ دارن، امتیاز IMDb روی گوشهٔ پوستر، دایرهٔ زرد/قرمز کنار اسم، و سال و دو ژانر اول زیرش. فیلمی که پوستر نداره، یه رنگ مخصوص خودش (از روی اسمش) می‌گیره.
- **جزئیات** از کنار صفحه باز می‌شه (با Esc یا ضربدر بسته می‌شه) و صفحهٔ آرشیو دیده می‌شه. بخش «اصلاح اطلاعات آنلاین» فقط وقتی باز می‌شه که فیلم حدسی یا مشکل‌دار باشه.
- لیست هاردهای وصل‌شده از صفحهٔ اصلی برداشته شد. پوشه‌های آرشیو (اضافه و حذف) تو پنجرهٔ دکمهٔ پوشه هستن. وقتی هارد جدا باشه، فقط تو جزئیات همون فیلم نوشته می‌شه.
- کلید `/` می‌پره رو کادر جستجو. فونت وزیرمتن داخل خود برنامه هست و نیازی به نصب نداره.

## جستجو، تب‌ها، ژانر و مرتب‌سازی

- کادر جستجوی بالا روی عنوان، اسم پوشه، ژانر و بازیگران کار می‌کنه و غلط املایی کوچیک رو تحمل می‌کنه. جستجوی حال‌وهوا (مثل «فیلم غمگین») نداره.
- سه تب: **همه / فیلم‌ها / سریال‌ها**. انیمه‌ها فعلاً فقط تو «همه» دیده می‌شن.
- ژانرها روی کارت و تو جزئیات به شکل تگ هستن. دکمهٔ **فیلترها** (کنار تب‌ها، با نشان تعداد فیلتر فعال) یه صفحهٔ فیلتر باز می‌کنه: وضعیت اطلاعات، ژانرها (با تعداد هر کدوم) و مرتب‌سازی. چند ژانر رو با هم قبول می‌کنه و فقط عنوان‌هایی رو نشون می‌ده که **همهٔ** ژانرهای انتخاب‌شده رو دارن. دکمهٔ «نمایش N مورد» تعداد نتیجه رو زنده نشون می‌ده، «پاک کردن همه» همه رو برمی‌داره. فیلترهای فعال زیر تب‌ها به شکل قرص‌های قابل حذف دیده می‌شن. تعدادها طبق تب، جستجو و فیلترهای دیگه حساب می‌شن.
- **کارت‌ها:** امتیاز IMDb روی پوستر نوشته می‌شه. اطلاعات تأییدشده علامتی نداره؛ **دایرهٔ زرد** کنار اسم یعنی حدسی بود؛ **دایرهٔ قرمز** یعنی نیاز به بررسی داره (چند نتیجه، هنوز پیدا نشده، پوشه خالیه یا از دیسک پاک شده). با نگه داشتن ماوس روی دایره دلیلش دیده می‌شه. هارد جدا شده دیگه دایره نداره و فقط تو جزئیات نوشته می‌شه.
- مرتب‌سازی: نام، سال (تازه‌ترین اول)، امتیاز (بیشترین اول، بدون امتیاز آخر)، تازه‌ترین (آخرین اضافه‌شده).
- تو جزئیات: کارگردان، جایزه‌ها، رده‌بندی سنی و کشور (به انگلیسی)، دکمهٔ «صفحهٔ IMDb» (تو مرورگر باز می‌شه) و کنار هر مکان دکمهٔ «باز کردن پوشه» که همون پوشه رو تو Explorer نشون می‌ده. وقتی هارد جدا باشه یا پوشه دیگه نباشه این دکمه غیرفعاله.

## سریال و انیمه: فصل‌ها و قسمت‌ها

تو جزئیات هر سریال، برای هر فصلی که پوشه‌اش رو داری یه بلوک بازشونده هست («فصل ۱ — ۲۳ قسمت»). هر قسمت شمارهٔ قسمت، اسم، تاریخ پخش، امتیاز IMDb و خلاصهٔ داستانش رو داره. اگه یه پوشه بدون شمارهٔ فصل داشته باشی (مثلاً کل سریال تو یه پوشه)، همهٔ فصل‌های سریال گرفته می‌شن.

قسمت‌ها با «دریافت اطلاعات» و **فقط از OMDb** گرفته می‌شن: اول فهرست فصل‌ها (یه درخواست برای هر فصل)، بعد داستان هر قسمت (یه درخواست برای هر قسمت). این کار درخواست زیاد می‌خواد، و چون سهمیهٔ رایگان روزی حدود ۱۰۰۰ درخواسته، برای سریال‌های بزرگ چند روز طول می‌کشه. وقتی سهمیه تموم شد برنامه می‌ایسته و روز بعد از همون جا ادامه می‌ده. قسمت‌هایی که داستانشون هنوز نیومده «داستان هنوز دریافت نشده» نشون می‌دن و زیر فصل‌ها نوشته می‌شه چند قسمت مونده.

انیمه‌ها همین سیستم رو دارن ولی از Jikan (MyAnimeList): فهرست قسمت‌ها و بعد داستان هر قسمت با فاصلهٔ کوتاه بین درخواست‌ها. همهٔ قسمت‌های یه انیمه زیر «فصل ۱» نشون داده می‌شه.

## ترجمهٔ فارسی

وقتی زبان برنامه فارسیه:

- **ژانرها** با یه فهرست ثابت ترجمه می‌شن (ژانر ناشناخته انگلیسی می‌مونه).
- **خلاصهٔ داستان فیلم و قسمت‌ها** با MyMemory ترجمه می‌شه. اول متن انگلیسی دیده می‌شه و وقتی ترجمه رسید جاش می‌شینه و یه یادداشت «ترجمهٔ ماشینی» کنارش می‌آد. ترجمهٔ قسمت‌ها وقتی یه فصل رو باز می‌کنی، یکی‌یکی انجام می‌شه.
- هر ترجمه **یک‌بار انجام و برای همیشه تو دیتابیس ذخیره می‌شه** و دفعهٔ بعد دوباره ترجمه نمی‌شه. متن‌های بلند به تکه‌های حداکثر ۴۵۰ نویسه شکسته می‌شن و هر تکه جدا ذخیره می‌شه، پس با رسیدن به سقف روزانه چیزی از دست نمی‌ره.
- نام فیلم‌ها و قسمت‌ها، جایزه‌ها و بازیگران انگلیسی می‌مونن.
- نسخهٔ رایگان MyMemory بدون ایمیل حدود ۵۰۰۰ نویسه تو روز می‌ده (چند فیلم). اگه تو «تنظیمات» یه ایمیل بنویسی (فقط برای MyMemory فرستاده می‌شه) حدود ۵۰۰۰۰ نویسه تو روز می‌ده. وقتی سهمیه تموم بشه متن انگلیسی می‌مونه و یه پیام می‌گه فردا امتحان کنی؛ پیام خطای MyMemory هیچ‌وقت به‌عنوان ترجمه ذخیره نمی‌شه.
- ترجمهٔ ماشینی ممکنه ضعیف باشه.

## محدودیت‌های شناخته‌شده

- فصل‌های مختلف یه انیمه (که تو MyAnimeList ورودی‌های جدا هستن) به یه ورودی وصل می‌شن.
- پوشهٔ دسته‌ای که سال تو اسمش باشه (مثل «Movies 2022») فیلم حساب می‌شه، مگه اینکه تو «پوشه‌های مجموعه» ثبت بشه.
- اسم پوشه‌های فارسی هنوز «نیاز به بررسی» می‌شن (باید عنوان انگلیسی رو دستی جستجو کنی).
- تب انیمه نداریم؛ انیمه‌ها فقط تو «همه» هستن.

## آپدیت از طریق گیت‌هاب

کد پروژه روی گیت‌هاب نگهداری می‌شه و برنامهٔ نصب‌شده خودش آپدیت می‌شه:

۱. شمارهٔ `version` داخل `package.json` رو بالا ببر (مثلاً `0.1.0` به `0.2.0`) و روی شاخهٔ `main` commit کن.
۲. این دو دستور رو بزن:

```
git tag v0.2.0
git push origin main --tags
```

۳. گیت‌هاب خودش تست‌ها رو اجرا می‌کنه، فایل نصب ویندوز رو می‌سازه و تو بخش Releases منتشر می‌کنه (تب Actions پیشرفتش رو نشون می‌ده). شمارهٔ تگ باید دقیقاً `v` به‌علاوهٔ شمارهٔ `version` باشه، وگرنه ساخت عمداً شکست می‌خوره.
۴. برنامه‌ای که قبلاً نصب شده موقع باز شدن دنبال نسخهٔ جدید می‌گرده و وقتی بسته بشه نسخهٔ جدید رو نصب می‌کنه. اگه اینترنت (یا دسترسی به گیت‌هاب) نباشه، بی‌صدا ردش می‌کنه.

دکمهٔ **بروزرسانی** (بالای برنامه، کنار تنظیمات) همین رو دستی انجام می‌ده: نسخهٔ جدید رو چک و دانلود می‌کنه، بعد همون دکمه می‌شه «نصب نسخهٔ X و راه‌اندازی دوباره». تو نسخهٔ نصب‌شده کار می‌کنه، نه با `npm start`.

مخزن گیت‌هاب باید عمومی (Public) باشه تا برنامه بتونه آپدیت رو بدون کلید دانلود کنه. چون فایل نصب امضا نشده، ویندوز اولین بار هشدار SmartScreen نشون می‌ده («More info» و بعد «Run anyway»).

فایل `AGENTS.md` (و `CLAUDE.md` که به اون اشاره می‌کنه) راهنمای پروژه برای عامل‌های هوش مصنوعی مثل Claude Code هست.
