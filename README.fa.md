# آرشیو فیلم

برنامه‌ای برای ویندوز که فیلم‌ها، سریال‌ها و انیمه‌های تو چند هارد مختلف رو فهرست می‌کنه. اسم هر پوشه رو می‌خونه، فیلم رو تشخیص می‌ده و پوستر، خلاصهٔ داستان و اطلاعاتش رو از IMDb (از طریق OMDb) می‌گیره. اگه چیزی تو IMDb پیدا نشد، برای انیمه از MyAnimeList (از طریق Jikan) استفاده می‌کنه. رابط برنامه فارسی و انگلیسیه.

برنامه هیچ فایلی روی هاردهات رو تغییر نمی‌ده، جابه‌جا نمی‌کنه و پاک نمی‌کنه. فقط اسم پوشه‌ها رو می‌خونه.

## نصب و اجرا

۱. Node.js (نسخهٔ ۲۲ یا بالاتر) رو نصب کن.
۲. تو پوشهٔ پروژه این دستورها رو بزن:

```
npm install
npm start
```

برای ساختن فایل نصب ویندوز (باید روی خود ویندوز اجرا بشه):

```
npm run dist
```

فایل نصب تو پوشهٔ `dist` ساخته می‌شه.

## کلید OMDb

برای گرفتن اطلاعات فیلم یه کلید رایگان لازمه. از سایت omdbapi.com کلید رایگان بگیر و تو «تنظیمات» وارد کن. نسخهٔ رایگان روزی حدود ۱۰۰۰ درخواست داره. اگه آرشیوت بزرگه، وقتی سهمیه تموم شد برنامه می‌ایسته و فردا با زدن «دریافت اطلاعات» از همون جا ادامه می‌ده.

## اضافه کردن پوشه‌های آرشیو

۱. هارد رو وصل کن.
۲. «پوشه‌های آرشیو» (منوی کناری) رو بزن، آدرس پوشهٔ فیلم‌ها رو بنویس (مثلاً `E:\Movies`) یا با «انتخاب…» پیداش کن و «افزودن پوشه» رو بزن. وقتی آرشیو خالیه، صفحهٔ اصلی خودش یه دکمهٔ «افزودن پوشه» نشون می‌ده.
۳. «اسکن پوشه‌ها» رو بزن. برنامه پوشه‌های زیر اون آدرس رو تا چند سطح می‌گرده (بخش «تشخیص پوشه‌ها» رو ببین).
۴. «دریافت اطلاعات» رو بزن تا پوستر و اطلاعات گرفته بشه.

### اسکن هوشمند

هر بار «اسکن پوشه‌ها» رو بزنی، فقط چیزهای جدید اضافه می‌شن. مثلاً دیروز ۱۱۰ فیلم اسکن کردی و امروز ۱۲۰ تا داری: ۱۱۰ فیلم قبلی با همهٔ اطلاعاتشون (پوستر، داستان، اصلاح‌های دستی، ترجمه) دست‌نخورده می‌مونن و ۱۰ فیلم جدید اضافه می‌شن. بعد از اسکن پیام می‌گه چند مورد جدید اضافه شد. «دریافت اطلاعات» هم فقط برای همون مورد‌های جدید درخواست می‌فرسته، پس سهمیهٔ OMDb الکی خرج نمی‌شه. پوشه‌ای که از هارد پاک یا عوض اسم بشه «پوشه گم شده» می‌گیره و از آرشیو پاک نمی‌شه.

### افزودن یک فیلم یا پوشهٔ تکی

اگه فقط یه فیلم (یا یه سریال) می‌خوای، نه کل یه پوشه: آدرس همون پوشه رو تو کادر بنویس و «افزودن یک فیلم/پوشه» رو بزن. فقط همون پوشه یه عنوان حساب می‌شه و پوشه‌های کنارش اسکن نمی‌شن (کنارش تو لیست برچسب «تکی» می‌خوره). اگه پوشه چند فصل داشته باشه، فصل‌ها جدا شناخته می‌شن. آدرس باید پوشه‌ای روی یه هارد متصل باشه، نه خودِ ریشهٔ هارد.

هر هارد با سریال خودش شناخته می‌شه، نه با حرف درایو. پس اگه یه روز حرف درایو عوض بشه، چیزی گم نمی‌شه. وقتی هارد جدا باشه، آرشیوش تو برنامه می‌مونه و برچسب «هارد جدا شده» می‌گیره.

پوشهٔ خالی هم تو آرشیو ثبت می‌شه و برچسب «پوشه خالی» می‌گیره. اگه پوشه‌ای بعداً حذف یا تغییر نام بده، برچسب «پوشه گم شده» می‌گیره و از آرشیو پاک نمی‌شه.

## تشخیص پوشه‌ها (اسکن بازگشتی)

برنامه فقط پوشه‌هایی رو می‌گرده که خودت اضافه کردی. هر پوشه به این ترتیب بررسی می‌شه:

1. اگه اسمش تو فهرست نادیده‌گرفتن باشه (`Subtitles`، `Extras`، `Specials`، `CD1`، `Disc 2` و مانند اون)، رد می‌شه.
2. **پوشهٔ فصل:** اسمش `S01`، `Season 1` یا `فصل 1` داره. اسم سریال متن قبل از اون توکنه؛ اگه خالی بود، اسم پوشهٔ بالاییه. پس `Mentalist/Mentalist S01` و `Mentalist/Season 1` هر دو می‌شن «Mentalist». داخل پوشهٔ فصل نمی‌ره و هر پوشهٔ فصل یه مکان حساب می‌شه.
3. **پوشهٔ سریال یا دسته:** اگه زیرپوشهٔ فصل داره، یا قبلاً در تنظیمات به‌عنوان مجموعه ثبت شده، یا فقط زیرپوشه داره (بدون فایل ویدیو و بدون سال تو اسمش)، داخلش می‌ره و خودش مکان حساب نمی‌شه.
4. غیر از اینا، **یه فیلم (یه عنوان)** حساب می‌شه، حتی اگه خالی باشه.

**پوشهٔ مجموعه (مثل Batman Trilogy):** اگه یه پوشه چند فیلم داخلش داشته باشه، به‌جای اینکه یه پوشهٔ ناقص حساب بشه، هر فیلمش جدا شناخته و به آرشیو اضافه می‌شه. فیلم‌ها می‌تونن زیرپوشه باشن (`Batman Begins (2005)`) یا خودِ فایل‌های ویدیو (`Batman.Begins.2005.1080p.mkv`)؛ برای فایل‌ها اسم فایل (بدون پسوند) اسم فیلم حساب می‌شه. نمونه (`sample`)، تریلر، قسمت‌های سریال (`S01E01`) و بخش‌های دیسک (`CD1`، `part1`) فیلم جدا حساب نمی‌شن. اگه پوشه خودش سال داشته باشه و فایل‌هاش سال نداشته باشن (مثل `Inception (2010)`) یه فیلم حساب می‌شه. خود پوشه هم تو آرشیو یه کارت «مجموعه · N عنوان» می‌گیره (فقط تو تب «همه») و وقتی روش بزنی، دکمهٔ «باز کردن پوشه» و فهرست فیلم‌های داخلش رو می‌بینی؛ با زدن روی هر فیلم می‌ری سراغ جزئیاتش. مجموعه‌ای که فقط یه عنوان داخلش باشه کارت جدا نمی‌گیره. برای فایل‌ها، «باز کردن پوشه» پوشهٔ نگه‌دارندهٔ فایل رو باز می‌کنه، نه خودِ فیلم رو.

فایل ویدیو یعنی `mkv mp4 avi mov wmv m4v ts m2ts mpg mpeg flv webm iso vob`. عمق بیشینه ۸ سطحه و شورتکات‌ها دنبال نمی‌شن. پوشه‌ای که برنامه نتونه بخونتش (مثلاً دسترسی نداره) «گم شده» حساب نمی‌شه.

## الگوی نام پوشه‌ها

تو «تنظیمات» می‌تونی بنویسی پوشه‌هات چه شکلی اسم‌گذاری شدن. هر خط یه الگوئه. این‌ها رو می‌تونی استفاده کنی:

- `{title}` اسم فیلم
- `{year}` سال ساخت
- `{season}` شمارهٔ فصل
- `*` هر چیز اضافه‌ای که بعدش می‌یاد

مثال‌ها:

| الگو | پوشه‌ای که می‌خونه | نتیجه |
| --- | --- | --- |
| `{title} {year}*` (پیش‌فرض) | `batman 2022` | The Batman، ۲۰۲۲ |
| `{title} {year}*` | `The.Batman.2022.1080p.BluRay` | The Batman، ۲۰۲۲ |
| `{title} ({year})*` | `Joker (2019) [1080p]` | Joker، ۲۰۱۹ |
| `{title} S{season}` | `Breaking Bad S02` | Breaking Bad، فصل ۲ |

فاصله، نقطه، خط تیره و آندرلاین یکی حساب می‌شن و فرق حروف بزرگ و کوچک مهم نیست. الگوها به ترتیب امتحان می‌شن و اولین الگوی درست استفاده می‌شه. اگه پوشه‌ای با هیچ الگویی نخونه، برنامه خودش حدس می‌زنه و برچسب «حدسی، بررسی کن» می‌ذاره.

پوشه‌هایی مثل `Subtitles`، `Extras` و پوشه‌های سیستمی خودکار نادیده گرفته می‌شن.

## برچسب‌ها

- **نیاز به بررسی:** برنامه فیلم رو مطمئن تشخیص نداد. روش بزن، از لیست پیشنهادها انتخاب کن یا لینک بده.
- **در انتظار اطلاعات:** هنوز «دریافت اطلاعات» برای این مورد اجرا نشده یا سهمیه تموم شده.
- **حدسی، بررسی کن:** الگوی شما با اسم پوشه نخوند و برنامه خودش اسم رو حدس زد.
- **پوشه خالی / پوشه گم شده / هارد جدا شده:** وضعیت پوشه روی هارد.

اسم پوشه‌های فارسی رو OMDb نمی‌شناسه. این‌ها «نیاز به بررسی» می‌شن و باید عنوان انگلیسی رو با لینک بدی. اسم فارسی پوشه همیشه قابل جستجوئه.

## تگ‌های من (دستی)

هر فیلم یا سریال رو می‌شه با تگ خودت علامت زد، مثلاً «ایرانی» یا «کلاسیک». روی کارت فیلم بزن تا جزئیات باز بشه، بخش **تگ‌های من** رو پیدا کن، تگ رو بنویس و Enter (یا ویرگول) بزن. با × کنار تگ حذفش می‌کنی. تگ‌هایی که قبلاً ساختی موقع تایپ پیشنهاد می‌شن.

- تگ دستی با ژانرهای برنامه فرق داره: ژانر یه قرص خالی خاکستریه، تگ دستی قرص رنگی با آیکن برچسبه (هم روی کارت، هم توی جزئیات).
- برای جدا کردن فیلم‌ها، **فیلترها** ← بخش **تگ‌های من** رو باز کن و تگ رو انتخاب کن. چند تگ رو با هم قبول می‌کنه (فقط فیلم‌هایی که **همهٔ** تگ‌ها رو دارن). تگ‌ها توی جستجوی بالا هم پیدا می‌شن.
- تگ به پوشهٔ فیلم وصله، پس بعد از اسکن مجدد یا «اصلاح اطلاعات آنلاین» سر جاش می‌مونه. اگه یه فیلم چند پوشه یا چند هارد داره، تگ برای همه‌شون ثبت می‌شه. فیلم‌های «نیاز به بررسی» (اسم فارسی) هم تگ می‌گیرن. پوشهٔ مجموعه (Collection) تگ نمی‌گیره؛ فیلم‌های داخلش جدا تگ می‌گیرن.
- هر تگ حداکثر ۳۰ نویسه‌ست. حذف پوشهٔ آرشیو از برنامه، تگ‌های فیلم‌هاش رو هم پاک می‌کنه.

## لیست کپی (فیلم‌ها از هاردهای مختلف توی یه پوشه)

1. روی هر فیلم یا سریال که می‌خوای کپی بشه کلیک کن و توی جزئیاتش **افزودن به لیست کپی** رو بزن. روی کارتش یه تیک می‌افته و روی «لیست کپی» (منوی کناری) تعداد نشون داده می‌شه.
2. آیکن **لیست کپی** رو بزن، اسم پوشهٔ جدید (مثلاً `claude`) رو بنویس و با **Browse** مقصد رو انتخاب کن.
3. برنامه همون‌جا می‌گه چند مورد و چند گیگ کپی می‌شه، کدوم‌ها هارد وصل ندارن و آیا جای خالی کافیه. بعد **شروع کپی** رو بزن. برنامه توی مقصد پوشه‌ای با اون اسم می‌سازه و فیلم‌ها رو توش می‌ریزه. نوار پیشرفت دیده می‌شه و **لغو کپی** هم هست.

- **فقط کپی:** از آرشیو چیزی پاک یا جابه‌جا نمی‌شه. مقصد نباید داخل پوشه‌های آرشیو باشه، وگرنه برنامه قبول نمی‌کنه.
- **انتخاب هوشمند:** اگه فیلمی روی چند هارد هست، از نسخه‌ای که هاردش وصله برمی‌داره و اگه چند هارد وصل باشه، نسخه‌ای رو ترجیح می‌ده که روی هاردِ مقصد نباشه (کپی بین دو هارد جدا سریع‌تره). سریال با همهٔ فصل‌هاش، داخل پوشه‌ای به اسم سریال کپی می‌شه. هاردها یکی‌یکی خونده می‌شن، نه همزمان.
- فایلی که از قبل توی مقصد باشه رو‌ش نوشته نمی‌شه (رد می‌شه). اگه وسط کار لغو کنی، فایل‌های کامل‌شده می‌مونن و فقط فایل نیمه‌کاره پاک می‌شه.
- کپی با خود برنامه انجام می‌شه، نه با پنجرهٔ TeraCopy یا Explorer. سرعتش به هارد بستگی داره.

## فیلتر کشور، انتخاب چندتایی، درگ و دراپ

- **کشور:** از OMDb خونده می‌شه و توی «فیلترها» بخش «کشور» هست (نام‌ها فارسی). چند کشور انتخاب کنی هر کدوم کافیه («یا»). فیلم‌های ایرانی خودشون جدا می‌شن.
- **انتخاب چندتایی:** دکمهٔ «انتخاب چندتایی» → کارت‌ها رو تیک بزن → نوار پایین: تگ زدن به همه، یا اضافه کردن همه به لیست کپی. روی یه پوشهٔ مجموعه (Collection) هم می‌شه تگ زد یا کپیش کرد؛ تگ روی همهٔ فیلم‌های داخلش می‌شینه و کپی یه‌جا انجام می‌شه.
- **درگ و دراپ:** پوشه یا فایل ویدیو رو بنداز روی پنجره؛ به برنامه اضافه و اسکن می‌شه. چیزی توی هارد تغییر نمی‌کنه.

## فیلم‌های مشابه

وقتی یه فیلم یا سریال رو باز می‌کنی، پایین توضیحاتش بخش «فیلم‌های مشابه توی آرشیو» هست: کارت‌های کوچیک از فیلم‌های دیگهٔ خودت که شبیهشه، با دلیل شباهت (مثلاً «کارگردان: …· ژانر: …»). روی هر کارت بزنی همون فیلم باز می‌شه.

شباهت از اطلاعاتی حساب می‌شه که OMDb قبلاً برای فیلم‌ها آورده (ژانر، کارگردان، بازیگران، کشور، سال) و تگ‌های خودت. هوش مصنوعی و اینترنت لازم نیست. فقط فیلم با فیلم و سریال با سریال مقایسه می‌شه، و فیلمی که هنوز شناسایی نشده پیشنهاد داده نمی‌شه. این بخش فقط فیلم‌های داخل آرشیو رو پیدا می‌کنه، نه فیلم‌هایی که نداری.

**انیمه:** برای انیمه، زیر «فیلم‌های مشابه» بخش «انیمه‌های پیشنهادی کاربران MyAnimeList» هم میاد (از Jikan، رایگان و بدون کلید). انیمه‌هایی که توی آرشیوته با برچسب «توی آرشیوته» (کلیک = باز شدن)، و بقیه با برچسب «توی آرشیو نیست» و تعداد رأی نشون داده می‌شن؛ کلیک روی اون‌ها صفحهٔ MyAnimeList رو توی مرورگر باز می‌کنه. جواب هر انیمه ذخیره می‌شه و دفعهٔ بعد اینترنت نمی‌خواد. این بخش فقط برای انیمه‌ست؛ برای فیلم‌های سینمایی پیشنهاد بیرون از آرشیو نداریم (OMDb چنین چیزی نمی‌ده).

## ترجمهٔ پس‌زمینهٔ داستان‌ها

وقتی زبان فارسیه و برنامه باز مونده، خلاصهٔ داستان فیلم‌ها از قبل ترجمه می‌شه (تنظیمات → ترجمهٔ خودکار). سهمیهٔ رایگان کمه (حدود ۵۰۰۰ نویسه در روز، با ایمیل ۵۰ هزار)؛ تموم شد، فردا ادامه پیدا می‌کنه. دکمهٔ «ترجمهٔ همهٔ داستان‌ها حالا» هم توی تنظیمات هست.

## منوی کناری

دکمه‌های کم‌کاربردتر (پوشه‌ها، تقویم سریال، کالکشن‌های من، لیست کپی، گزارش‌ها، بروزرسانی، تنظیمات، تم و زبان) با اسم کنار آیکن توی یه منوی کناری هستن؛ بالای صفحه فقط جستجو، «اسکن پوشه‌ها» و «دریافت اطلاعات» می‌مونه. با «جمع کردن منو» فقط آیکن‌ها می‌مونن (اسمشون با نگه داشتن موس دیده می‌شه) و انتخابت یادش می‌مونه. توی پنجرهٔ باریک منو خودش به یه نوار آیکن زیر هدر تبدیل می‌شه.

## تقویم سریال و «در حال پخش»

- «تقویم سریال» (منوی کناری): اسم سریال + روز هفته + ساعت + شمارهٔ قسمت بعدی. ساعت رو می‌شه تایپ کرد (`2030`، `8:5`، `۲۰:۳۰`)، با کلید بالا/پایین جابه‌جا کرد (۵ دقیقه‌ای؛ با Shift یک ساعتی)، یا با دکمهٔ ساعت کنارش پنجرهٔ ساعت رو باز کرد: روی صفحهٔ ۲۴ ساعته اول ساعت و بعد دقیقه رو بزن، یا یکی از ساعت‌های پرکاربرد (۱۸ تا ۲۳) رو انتخاب کن. هر وقت برنامه باز باشه، سر ساعت اعلان «قسمت X منتشر شد» میاد؛ اگه برنامه بسته بود، موقع باز کردن خلاصهٔ چیزهایی که اومدن نشون داده می‌شه.
- با تیک زدن «گرفتم»، برنامه خودش یادآور هفتهٔ بعد رو با قسمت بعدی می‌سازه. می‌تونی هر یادآور رو ویرایش، رد یا حذف کنی.
- توی کارت سریال گزینهٔ «در حال پخش» هست (برای سریال‌های تموم‌شده نشون داده نمی‌شه). روز و ساعت پخش رو بده تا یادآور همون سریال ساخته بشه.
- یادآورها فقط وقتی برنامه بازه کار می‌کنن (اعلان ویندوز وقتی بسته‌ست نداریم).

## لیست‌های کپی نام‌دار و بررسی کپی

- چند لیست کپی بساز، هر کدوم اسم و مقصد خودش رو داره (اسم لیست = اسم پوشهٔ مقصد). لیست‌ها بعد از بستن برنامه می‌مونن.
- موقع کپی برای هر فایل SHA-256 ذخیره می‌شه. بعد از کپی، برنامه خودش مقصد رو کامل بررسی می‌کنه و اگه فایلی کم یا خراب بود، دوباره کپی و دوباره بررسی می‌کنه.
- موقع کپی، سرعت لحظه‌ای (میانگین چند ثانیهٔ آخر) و زمان تقریبی باقی‌مونده نشون داده می‌شه.
- برنامه تک‌نسخه‌ایه: اگه دوباره بازش کنی، پنجرهٔ قبلی میاد جلو و نسخهٔ دوم باز نمی‌شه. شمارهٔ نسخه کنار اسم برنامه (بالای صفحه) نوشته شده.
- توی پنجرهٔ کپی، بخش «کپی‌های انجام‌شده»: **بررسی سریع** (وجود + حجم)، **بررسی کامل** (هش دوباره)، **تعمیر** (کپی مجدد فقط موارد خراب). بررسی بدون هارد مبدأ هم کار می‌کنه؛ تعمیر به هارد مبدأ نیاز داره.

## اصلاح اطلاعات آنلاین

اگه اطلاعات یه فیلم اشتباهه، روش بزن و تو بخش «اصلاح اطلاعات آنلاین» لینک IMDb یا OMDb اون فیلم رو بذار، مثلاً:

```
https://www.imdb.com/title/tt1877830/
```

برنامه شناسهٔ `tt...` رو از لینک درمیاره و اطلاعات و پوستر رو با همون شناسه عوض می‌کنه. این اصلاح ثابت می‌مونه و اسکن‌های بعدی عوضش نمی‌کنن. اگه تو لینک OMDb کلید API باشه، برنامه نادیده‌ش می‌گیره و فقط کلید تنظیمات رو استفاده می‌کنه. این گزینه برای انیمه‌هایی که از MyAnimeList اومدن فعلاً لینک MyAnimeList رو قبول نمی‌کنه.

## وقتی OMDb اسم پوشه رو پیدا نکنه

برنامه تو OMDb جستجو می‌کنه. اگه یه نتیجهٔ واضح باشه (هم‌اسم یا خیلی نزدیک، و سالش حداکثر یه سال فرق داشته باشه)، خودش وصلش می‌کنه و برچسب «حدسی، بررسی کن» می‌ذاره. اگه چند نتیجه باشه (مثلاً Dune ۱۹۸۴ و ۲۰۲۱ وقتی سال تو اسم پوشه نیست)، «نیاز به بررسی» می‌شه و خودت از لیست انتخاب می‌کنی. نتیجهٔ جستجوها تو دیتابیس می‌مونه و تکراری پرسیده نمی‌شه.

## ظاهر برنامه

- **تم تیره و روشن:** «تم تیره / روشن» در منوی کناری. تا انتخاب نکنی، تم سیستم ویندوز رو دنبال می‌کنه و انتخابت یادش می‌مونه.
- **صفحه پوستر محوره:** کارت‌ها پوستر بزرگ دارن، امتیاز IMDb روی گوشهٔ پوستر، دایرهٔ زرد/قرمز کنار اسم، و سال و دو ژانر اول زیرش. فیلمی که پوستر نداره، یه رنگ مخصوص خودش (از روی اسمش) می‌گیره.
- **جزئیات** از کنار صفحه باز می‌شه (با Esc یا ضربدر بسته می‌شه) و صفحهٔ آرشیو دیده می‌شه. بخش «اصلاح اطلاعات آنلاین» فقط وقتی باز می‌شه که فیلم حدسی یا مشکل‌دار باشه.
- لیست هاردهای وصل‌شده از صفحهٔ اصلی برداشته شد. پوشه‌های آرشیو (اضافه و حذف) تو پنجرهٔ دکمهٔ پوشه هستن. وقتی هارد جدا باشه، فقط تو جزئیات همون فیلم نوشته می‌شه.
- کلید `/` می‌پره رو کادر جستجو. فونت وزیرمتن داخل خود برنامه هست و نیازی به نصب نداره.

## جستجو، تب‌ها، ژانر و مرتب‌سازی

- کادر جستجوی بالا روی عنوان، اسم پوشه، ژانر و بازیگران کار می‌کنه و غلط املایی کوچیک رو تحمل می‌کنه. جستجوی حال‌وهوا (مثل «فیلم غمگین») نداره.
- سه تب: **همه / فیلم‌ها / سریال‌ها**. انیمه‌ها فعلاً فقط تو «همه» دیده می‌شن.
- ژانرها روی کارت و تو جزئیات به شکل تگ هستن. دکمهٔ **فیلترها** (کنار تب‌ها، با نشان تعداد فیلتر فعال) یه صفحهٔ فیلتر باز می‌کنه: وضعیت اطلاعات، ژانرها (با تعداد هر کدوم) و مرتب‌سازی. چند ژانر رو با هم قبول می‌کنه و فقط عنوان‌هایی رو نشون می‌ده که **همهٔ** ژانرهای انتخاب‌شده رو دارن. دکمهٔ «نمایش N مورد» تعداد نتیجه رو زنده نشون می‌ده، «پاک کردن همه» همه رو برمی‌داره. فیلترهای فعال زیر تب‌ها به شکل قرص‌های قابل حذف دیده می‌شن. تعدادها طبق تب، جستجو و فیلترهای دیگه حساب می‌شن.
- **کارت‌ها:** امتیاز IMDb روی پوستر نوشته می‌شه. اطلاعات تأییدشده علامتی نداره؛ **دایرهٔ زرد** کنار اسم یعنی حدسی بود؛ **دایرهٔ قرمز** یعنی نیاز به بررسی داره (چند نتیجه، هنوز پیدا نشده، پوشه خالیه یا از دیسک پاک شده). با نگه داشتن ماوس روی دایره دلیلش دیده می‌شه. هارد جدا شده دیگه دایره نداره و فقط تو جزئیات نوشته می‌شه.
- مرتب‌سازی: نام، سال (تازه‌ترین اول)، امتیاز (بیشترین اول، بدون امتیاز آخر)، تازه‌ترین (آخرین اضافه‌شده).
- تو جزئیات: کارگردان، جایزه‌ها، رده‌بندی سنی و کشور (به انگلیسی)، دکمهٔ «صفحهٔ IMDb» (تو مرورگر باز می‌شه) و کنار هر مکان دکمهٔ «باز کردن پوشه» که همون پوشه رو تو Explorer نشون می‌ده. وقتی هارد جدا باشه یا پوشه دیگه نباشه این دکمه غیرفعاله.

## سریال و انیمه: فصل‌ها و قسمت‌ها

تو جزئیات هر سریال، برای هر فصلی که پوشه‌اش رو داری یه بلوک بازشونده هست («فصل ۱ — ۲۳ قسمت»). هر قسمت شمارهٔ قسمت، اسم، تاریخ پخش، امتیاز IMDb و خلاصهٔ داستانش رو داره. اگه یه پوشه بدون شمارهٔ فصل داشته باشی (مثلاً کل سریال تو یه پوشه)، همهٔ فصل‌های سریال گرفته می‌شن.

قسمت‌ها با «دریافت اطلاعات» و **فقط از OMDb** گرفته می‌شن: اول فهرست فصل‌ها (یه درخواست برای هر فصل)، بعد داستان هر قسمت (یه درخواست برای هر قسمت). این کار درخواست زیاد می‌خواد، و چون سهمیهٔ رایگان روزی حدود ۱۰۰۰ درخواسته، برای سریال‌های بزرگ چند روز طول می‌کشه. وقتی سهمیه تموم شد برنامه می‌ایسته و روز بعد از همون جا ادامه می‌ده. قسمت‌هایی که داستانشون هنوز نیومده «داستان هنوز دریافت نشده» نشون می‌دن و زیر فصل‌ها نوشته می‌شه چند قسمت مونده.

انیمه‌ها همین سیستم رو دارن ولی از Jikan (MyAnimeList): فهرست قسمت‌ها و بعد داستان هر قسمت با فاصلهٔ کوتاه بین درخواست‌ها. همهٔ قسمت‌های یه انیمه زیر «فصل ۱» نشون داده می‌شه.

## ترجمهٔ فارسی

وقتی زبان برنامه فارسیه:

- **ژانرها** با یه فهرست ثابت ترجمه می‌شن (ژانر ناشناخته انگلیسی می‌مونه).
- **خلاصهٔ داستان فیلم و قسمت‌ها** با MyMemory ترجمه می‌شه. اول متن انگلیسی دیده می‌شه و وقتی ترجمه رسید جاش می‌شینه و یه یادداشت «ترجمهٔ ماشینی» کنارش می‌آد. ترجمهٔ قسمت‌ها وقتی یه فصل رو باز می‌کنی، یکی‌یکی انجام می‌شه.
- هر ترجمه **یک‌بار انجام و برای همیشه تو دیتابیس ذخیره می‌شه** و دفعهٔ بعد دوباره ترجمه نمی‌شه. متن‌های بلند به تکه‌های حداکثر ۴۵۰ نویسه شکسته می‌شن و هر تکه جدا ذخیره می‌شه، پس با رسیدن به سقف روزانه چیزی از دست نمی‌ره.
- نام فیلم‌ها و قسمت‌ها، جایزه‌ها و بازیگران انگلیسی می‌مونن.
- نسخهٔ رایگان MyMemory بدون ایمیل حدود ۵۰۰۰ نویسه تو روز می‌ده (چند فیلم). اگه تو «تنظیمات» یه ایمیل بنویسی (فقط برای MyMemory فرستاده می‌شه) حدود ۵۰۰۰۰ نویسه تو روز می‌ده. وقتی سهمیه تموم بشه متن انگلیسی می‌مونه و یه پیام می‌گه فردا امتحان کنی؛ پیام خطای MyMemory هیچ‌وقت به‌عنوان ترجمه ذخیره نمی‌شه.
- ترجمهٔ ماشینی ممکنه ضعیف باشه.

## انیمیشن و انیمه

کنار «همه»، «فیلم‌ها» و «سریال‌ها» دو بخش دیگه هست: **انیمیشن** (هر عنوانی که ژانرش Animation باشه) و **انیمه** (عنوان‌هایی که از MyAnimeList اومدن، یا انیمیشن ساخت ژاپن). این‌ها دیگه توی تب فیلم‌ها و سریال‌ها تکرار نمی‌شن؛ توی «همه» همه چیز هست. توی کاتالوگ موبایل هم همین بخش‌ها هست.

## کیفیت، دوبله و زیرنویس

از روی اسم پوشه (و پوشه‌های بالاترش) تشخیص داده می‌شه: کیفیت (4K، 1080p، 720p)، «دوبله فارسی» (دوبله، Dubbed، دو زبانه) و زیرنویس (زیرنویس، Sub، و «زیرنویس چسبیده» یا HardSub). روی کارت‌ها نشان کوچیک میاد و توی «فیلترها» بخش «کیفیت، دوبله و زیرنویس» هست؛ مثلاً فقط دوبله‌ها. فایل‌ها باز نمی‌شن، فقط اسم پوشه خونده می‌شه.

اگه تشخیص خودکار اشتباه بود یا اسم پوشه چیزی نمی‌گفت، توی کارت فیلم/سریال بخش «دوبله و زیرنویس» دو دکمه داره: هر کدوم رو می‌تونی روشن یا خاموش کنی (و هر دو با هم هم می‌شه). علامت دستی با اسکن مجدد و بازیابی پشتیبان می‌مونه. اگه دکمه رو دوباره به حالت تشخیص خودکار برگردونی، علامت دستی پاک می‌شه.

## جستجوی فارسی و نام‌های دیگر

جستجو بین «ی/ي»، «ک/ك»، «آ/ا» و عددهای فارسی/عربی/لاتین فرق نمی‌ذاره، و نیم‌فاصله رو نادیده می‌گیره. توی صفحهٔ هر فیلم بخش «نام‌های دیگر» هست: اسم فارسی یا هر اسم دیگه‌ای رو بنویس (Enter) تا با اون هم پیدا بشه. این اسم‌ها به پوشه وصلن و با اسکن دوباره یا اصلاح آنلاین از بین نمی‌رن.

## مشتری‌ها: سابقهٔ تحویل، قیمت، فاکتور و فلش

توی پنجرهٔ کپی می‌تونی **اسم مشتری** (و تلفن و یادداشت) بنویسی. بعد از هر کپی موفق یه «سفارش» ثبت می‌شه. اگه فیلمی رو برای مشتری‌ای اضافه کنی که قبلاً همون رو گرفته، همون‌جا هشدار «قبلاً تحویل داده شده» می‌بینی (این تنها استثنا در مورد «سابقه» است؛ «دیده‌شده» و «علاقه‌مندی» همچنان نداریم). سابقهٔ همهٔ مشتری‌ها توی گزارش‌ها (آیکن نمودار) → «سابقهٔ تحویل» هست، با فیلتر اسم، چاپ دوبارهٔ فاکتور و حذف رکورد (فقط رکورد پاک می‌شه، فایلی پاک نمی‌شه).

- **قیمت:** توی تنظیمات بخش «فاکتور و قیمت»، «قیمت هر فیلم»، «قیمت هر فصل» و «قیمت هر قسمت» (وقتی فقط چند قسمت از یک فصل داده می‌شه) رو بنویس (۰ یعنی نداره) و اسم فروشگاه. حجم فایل‌ها توی قیمت حساب نمی‌شه. جمع قیمت توی پنجرهٔ کپی و فاکتور میاد، فقط وقتی حداقل یکی از قیمت‌ها پر باشه. زیر قیمت‌ها یه **ماشین‌حساب** هست: تعداد فیلم و فصل و قسمت رو بنویس تا قیمت نهایی رو ببینی. با همون قیمت‌هایی که الان توی فرم نوشتی حساب می‌کنه، حتی ذخیره‌نشده.
- **فاکتور:** بعد از کپی، دکمهٔ «چاپ فاکتور» (پنجرهٔ چاپ ویندوز؛ می‌تونی PDF هم ذخیره کنی).
- **فلش:** پنجرهٔ کپی حجم کل فیلم‌ها و جای خالی مقصد رو زنده نشون می‌ده و اگه جا نشه هشدار می‌ده؛ درایوهای قابل‌جابه‌جایی (فلش) تشخیص داده می‌شن و بعد از کپی و بررسی، دکمهٔ «خارج کردن امن» هست.
- **درخواست‌ها:** گزارش‌ها → «درخواست‌ها»: فیلم‌هایی که مشتری خواسته و نداری. هر بار دوباره بخوان عددش بالا می‌ره؛ اگه همون فیلم توی آرشیو باشه بهت می‌گه.

## گزارش‌ها، فهرست چاپی و پشتیبان

- **سریال‌های ناقص:** شمارهٔ قسمت‌ها از اسم فایل‌ها خونده می‌شه و با قسمت‌های پخش‌شدهٔ OMDb مقایسه می‌شه («فصل ۳: ۸ از ۱۰، نیست: ۴، ۷»). فقط هاردهای وصل‌شده بررسی می‌شن.
- **فقط روی یک هارد:** فیلم و سریال‌هایی که یه نسخه بیشتر ندارن؛ برای تصمیم دربارهٔ پشتیبان‌گیری.
- **فهرست چاپی:** کل آرشیو بر اساس ژانر، آمادهٔ چاپ یا ذخیره PDF (توی پنجرهٔ چاپ «Microsoft Print to PDF»).
- **پشتیبان:** تنظیمات → «ذخیرهٔ پشتیبان» / «بازیابی». تگ‌ها، نام‌های دیگر، لیست‌های کپی، یادآورهای تقویم، سابقهٔ کپی و تحویل، درخواست‌ها و تنظیمات (بدون کلید OMDb) توی یه فایل JSON می‌رن. خود آرشیو ذخیره نمی‌شه؛ با اسکن دوباره برمی‌گرده.

## کاتالوگ موبایلی (QR)

تنظیمات → «روشن کردن کاتالوگ». برنامه یه صفحهٔ فقط‌خواندنی روی شبکهٔ همین مغازه راه می‌ندازه و یه QR و آدرس نشون می‌ده؛ مشتری با گوشی‌اش (به همون وای‌فای وصل باشه) اسکن می‌کنه، فیلم‌ها رو می‌گرده، چندتا انتخاب می‌کنه و با اسم و شماره «ارسال لیست» می‌زنه. لیست‌ها توی گزارش‌ها → «لیست مشتری‌ها از موبایل» میان و با یه دکمه می‌رن توی لیست کپی، همراه اسم مشتری.

- صفحهٔ مشتری فارسی/انگلیسی داره (دکمهٔ بالا)، تب فیلم/سریال/انیمه، مرتب‌سازی (تازه‌اضافه‌شده، امتیاز، سال، الفبا)، فیلتر ژانر و جستجو با اسم فارسی/انگلیسی، بازیگر یا کارگردان. اگه فیلمی رو پیدا نکرد، همون‌جا «درخواست» می‌زنه (اگه فیلم رو داشته باشی بهش می‌گه، و فقط فیلم‌های نداشته توی «درخواست‌ها» شمرده می‌شن). بعد از «ارسال لیست» یه شمارهٔ پیگیری می‌گیره.
- وقتی لیست تازه برسه، روی آیکن گزارش‌ها یه عدد میاد و پایین برنامه خبر می‌ده؛ فیلم‌هایی که اون مشتری قبلاً گرفته توی لیست علامت می‌خورن.
- پیش‌فرض خاموشه و هر وقت بخوای خاموشش می‌کنی؛ اگه روشن بمونه، دفعهٔ بعد هم با برنامه روشن می‌شه.
- فقط اسم، پوستر، سال، ژانر و کیفیت فیلم‌ها دیده می‌شه؛ مسیر پوشه و هارد هیچ‌وقت نه. مشتری هیچ چیزی رو نمی‌تونه تغییر بده، فقط لیست می‌فرسته (حداکثر ۵ لیست در ۱۰ دقیقه از هر گوشی).
- **با اینترنت خود مشتری:** وقتی کاتالوگ روشنه، پایینش دکمهٔ «باز کردن برای اینترنت مشتری» هست. یه آدرس https عمومی از Cloudflare می‌سازه (بدون تنظیم مودم و بدون IP ثابت) و یه QR جدا نشون می‌ده؛ مشتری با دیتای گوشی‌اش اسکن می‌کنه و لازم نیست به وای‌فای مغازه وصل بشه. برنامهٔ cloudflared بار اول خودش از سایت رسمی Cloudflare دانلود می‌شه (پوشهٔ داده‌های برنامه)، پس کامپیوتر مغازه باید اینترنت داشته باشه. آدرس هر بار که روشن می‌کنی عوض می‌شه و QR قدیمی کار نمی‌کنه. محدودیت «۵ لیست در ۱۰ دقیقه» از این راه هم برای هر گوشی جدا حساب می‌شه. این بخش روی ویندوز واقعی و اینترنت واقعی تست نشده.
- ویندوز دفعهٔ اول ممکنه برای فایروال اجازه بخواد؛ «Private networks» رو تیک بزن. این بخش روی شبکهٔ واقعی تست نشده.

## محدودیت‌های شناخته‌شده

- فصل‌های مختلف یه انیمه (که تو MyAnimeList ورودی‌های جدا هستن) به یه ورودی وصل می‌شن.
- پوشهٔ دسته‌ای که سال تو اسمش باشه (مثل «Movies 2022») فیلم حساب می‌شه، مگه اینکه قبلاً در تنظیمات به‌عنوان مجموعه ثبت شده باشه.
- اسم پوشه‌های فارسی هنوز «نیاز به بررسی» می‌شن (باید عنوان انگلیسی رو دستی جستجو کنی).
- تب انیمه نداریم؛ انیمه‌ها فقط تو «همه» هستن.

## آپدیت از طریق گیت‌هاب

کد پروژه روی گیت‌هاب نگهداری می‌شه و برنامهٔ نصب‌شده خودش آپدیت می‌شه:

**ساخت ریلیز (دستی، بدون تگ و بدون تغییر فایل):**

۱. توی گیت‌هاب برو به تب **Actions** ← **CI and release** ← دکمهٔ **Run workflow**.
۲. شمارهٔ نسخه رو تایپ کن (مثلاً `0.4.1`؛ باید از ریلیز قبلی بزرگ‌تر باشه) و **Run workflow** رو بزن.
۳. گیت‌هاب شمارهٔ نسخه رو موقع ساخت خودش توی `package.json` می‌نویسه (لازم نیست چیزی commit کنی)، فایل نصب ویندوز و فایل `AppImage` لینوکس رو هم‌زمان می‌سازه و ریلیز `v0.4.1` رو (با تگ) با هر دو فایل منتشر می‌کنه. اگه یکی از دو ساخت خراب بشه، ریلیز نیمه‌کاره پاک می‌شه و می‌تونی همون نسخه رو دوباره بزنی. اگه اون نسخه قبلاً ریلیز شده باشه یا قالبش درست نباشه، ساخت متوقف می‌شه و می‌گه چرا.

روش با تگ (`git tag v0.4.1` و `git push origin main --tags`) هم هنوز کار می‌کنه و نسخه رو از اسم تگ برمی‌داره.

**توی برنامه:** چند ثانیه بعد از باز شدن (و هر ۶ ساعت) برنامه بی‌صدا دنبال نسخهٔ جدید می‌گرده. اگه پیدا کنه، بالای صفحه نوار «نسخهٔ جدید X آماده‌ست» با دکمه‌های **بروزرسانی** و **بعداً** میاد. با «بروزرسانی» دانلود با درصد شروع می‌شه، بعد نصب می‌شه و برنامه خودش دوباره باز می‌شه. اگه چیزی پیدا نشه یا اینترنت نباشه، هیچ‌چیزی نشون داده نمی‌شه.

دکمهٔ **بروزرسانی** (بالای برنامه) همین بررسی رو دستی انجام می‌ده و اگه نسخهٔ جدید باشه همون نوار رو نشون می‌ده. تو نسخهٔ نصب‌شده کار می‌کنه، نه با `npm start`.

**لینوکس:** فایل `Movie-Archive-<نسخه>.AppImage` رو از صفحهٔ Releases بگیر، `chmod +x` بزن و اجرا کن (نصب نمی‌خواد؛ بعضی توزیع‌ها برای AppImage بستهٔ `fuse2`/`libfuse2` می‌خوان). درایوها با `lsblk` و شناسهٔ UUID فایل‌سیستم تشخیص داده می‌شن (مثل سریال درایو در ویندوز)، پس هاردی که جای دیگه mount بشه همون آرشیوه. آپدیت خودکار فقط وقتی کار می‌کنه که برنامه از خود فایل AppImage اجرا بشه. لیست فلش و دکمهٔ «خروج امن» فقط ویندوزه. این نسخه روی لینوکس واقعی تست نشده (فقط ساخته و بالا آوردنش دیده شده).

مخزن گیت‌هاب باید عمومی (Public) باشه تا برنامه بتونه آپدیت رو بدون کلید دانلود کنه. چون فایل نصب امضا نشده، ویندوز اولین بار هشدار SmartScreen نشون می‌ده («More info» و بعد «Run anyway»).

فایل `AGENTS.md` (و `CLAUDE.md` که به اون اشاره می‌کنه) راهنمای پروژه برای عامل‌های هوش مصنوعی مثل Claude Code هست.

## درآمد، بدهی و پرداخت

- موقع کپی برای مشتری، فیلد «پرداخت‌شده الان (خالی = کامل)» هست. اگه خالی بذاری یعنی کل مبلغ پرداخت شده؛ اگه کمتر بنویسی، بقیه‌اش به‌عنوان بدهی می‌مونه. اسم مشتری که از قبل بدهکار باشه، همون‌جا بالای فرم یادآوری می‌شه.
- گزارش‌ها ← «سابقهٔ تحویل»: روی هر سفارش مانده نوشته می‌شه و فیلد «ثبت پرداخت» داره (مبلغ به پرداخت‌شده‌ها اضافه می‌شه و از مبلغ سفارش بیشتر نمی‌شه). فاکتور هم پرداخت‌شده و مانده رو نشون می‌ده.
- گزارش‌ها ← «درآمد و پرفروش‌ها»: جمع سفارش و درآمد و دریافتی و مانده (۳۰ روز، ۹۰ روز یا همه)، لیست بدهکارها با شماره، جدول ماهانه و روزانه، و فیلم‌هایی که بیشتر از همه کپی شدن. فقط حسابداری مغازه‌ست، چیزی دربارهٔ «دیدن فیلم» ثبت نمی‌شه. سفارش‌های قدیمی، قبل از این قابلیت، «کاملاً پرداخت‌شده» حساب می‌شن.

## خبر دادن به مشتری وقتی فیلم درخواستی رسید

- توی کاتالوگ موبایلی، بخش «پیدا نکردی؟» دو فیلد اختیاری دارد: اسم و شماره. اگه مشتری پر کنه، همراه درخواست ثبت می‌شه (هر نفر یک بار).
- بعد از اسکن (و چند ثانیه بعد از باز شدن برنامه) اگه فیلمی که خواسته شده بود توی آرشیو باشه، پایین برنامه خبر می‌ده. گزارش‌ها ← «درخواست‌ها» بالای لیست، فیلم‌های رسیده رو با اسم و شمارهٔ مشتری‌ها نشون می‌ده؛ «کپی متن پیام» یه پیام آماده می‌ده که می‌تونی توی واتساپ/ایتا/پیامک بفرستی، و «خبر دادم» اون مشتری رو از لیست برمی‌داره.

## تکراری‌ها و فضای هدررفته

گزارش‌ها ← «تکراری‌ها»: فیلم یا فصلی که توی چند پوشه (روی یک یا چند هارد) هست، با حجم و کیفیت هر نسخه و اینکه اگه فقط بزرگ‌ترین بمونه چقدر جا آزاد می‌شه. برنامه چیزی پاک نمی‌کنه؛ با «باز کردن پوشه» خودت تصمیم می‌گیری. حجم نسخه‌ای که هاردش وصل نیست «نامعلوم» نوشته می‌شه.
